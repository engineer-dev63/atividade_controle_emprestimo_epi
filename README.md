# SafeWork EPI 🛡️ • Sistema de Gerenciamento de EPIs

> **Projeto de Software para o Setor Têxtil** > Solução computacional robusta e intuitiva desenvolvida para automatizar e auditar o controle de empréstimos e devoluções de Equipamentos de Proteção Individual (EPIs).

---

## 📋 Contextualização

Em auditorias internas da indústria têxtil, identificou-se uma fragilidade crítica: o esquecimento e a não retirada de EPIs por parte dos colaboradores no departamento de Saúde e Segurança do Trabalho (SST). 

O **SafeWork EPI** resolve esse problema através de uma interface intuitiva e aderente às Normas Regulamentadoras (NRs). Ele serve como um livro de registro digital inviolável, permitindo o cadastro centralizado de equipamentos, colaboradores, usuários controladores e o histórico completo de empréstimos em tempo real.

---

## Tecnologias que foram Utilizadas

O projeto adota padrões modernos de arquitetura, focando em manutenibilidade e experiência do usuário (UX):
* **Front-end:** HTML5, CSS3, JavaScript
* **Framework Visual:** Bootstrap 5
* **Banco de Dados:** MySQL
